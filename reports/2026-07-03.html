我们很高兴在 #ICML2026 上展示我们的最新研究，“Bridging Spherical Black-Box Optimizers”

https://t.co/3FT6vn0dSn

当通过模拟器、外部 API 或在强化学习中进行优化时，梯度通常是不可用的。Black-Box Optimization (BBO) 填补了这一空白，但该领域在历史上一直被分为两类：

1. Parametric Methods：像 Evolution Strategies (ES) 这样的算法可以扩展到高维，但只能找到单个解。

2. Nonparametric Methods：像 Consensus-Based Optimization (CBO) 这样的算法可以找到多个解，但在高维中会失效。

我们的团队提出了一个简单的问题：如果它们其实都在做同样的事情呢？

在我们的论文中，我们证明了这些不同的系列实际上是单个更新方程的变体。通过弥合这一理论差距，我们现在可以针对特定任务设计定制的混合优化器。

这方面的一个关键应用是合并 foundation models。在我们之前关于 Evolutionary Model Merging 的工作基础上，我们面临着计算挑战。在每一步评估 large language models 都是资源密集型的，但使用较小的评估数据集会导致标准的单模态优化器过拟合。

通过将 LLM 合并视为一个多模态问题，并部署我们新开发的混合优化器 AdaPol 和 SchedPol，我们成功解决了这个问题。这些算法在较小的数据集上识别出了多个不同的 optima，使我们能够以极低的计算成本找到泛化、高质量的 merges。
▶
💡统一了参数化与非参数化黑盒优化（BBO）理论，推出AdaPol和SchedPol混合优化器，能在小数据集上低成本寻找多个局部最优解。这意味着模型合并（Model Merging）的计算成本将大幅降低，从业者可利用小样本快速定制高性能混合模型。

介绍 EdgeBench，这是一个旨在研究 agent 如何在至少 12~72-hour 的运行中从环境中学习的基准测试。我们发现，性能与环境交互时间高度精确地遵循 log-sigmoid 函数关系。

EdgeBench 构建于三个核心要素：

- 🌍 真实与多样：涵盖 6 个任务类别的 134 个真实世界任务，跨越科学问题、专业知识工作、软件工程、优化、形式数学和游戏。
- ⏳ 超长跨度：每个任务支持 12–72 小时的 agent 工作。记录的人类投入平均为 57.2 小时。
- 🔁 信息丰富的反馈：agent 接收真实世界的反馈以进行持续改进。

在 EdgeBench 上进行了 38,000 小时的 agent 运行后，一种从环境中学习的 scaling law 显现出来：

- 📈 随着 agent 随时间与任务环境进行交互，它们的总体性能被精确地拟合为 log-sigmoid 函数。
- 🧠 这一现象可以通过一个优雅的图探索理论来解释。

我们正在发布 134 个任务中的首批 51 个，以及完整的评估框架，以帮助推动长跨度 agent 研究。查看我们的博客和论文以获取更多发现！
