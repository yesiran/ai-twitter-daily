GPT-6 Astra 代表了模型在交互式推理问题能力上的阶跃式提升。使用我们的 standard harness 时，它在 ARC-AGI-3 上的得分为 66%；而配合 continuous conversation harness 和自定义 compaction，得分接近 100%，每局游戏的成本约为 $360。

事实上，continuous harness 版本在几乎所有关卡的动作效率上都显著优于我们的人类 baseline。当我们检查推理链以理解模型的运作机制时，发现它针对每局游戏和关卡执行了极高效的即时符号化世界建模（on-the-fly symbolic world modeling）。它甚至开发出了一套专属的速记 DSL 来表示游戏内局势——本质上是一种针对特定游戏的代数记号（algebraic notation）。

总体而言，Astra 展现出了我们此前只有在复杂 harness 中才见过的符号建模行为——这意味着 harness 的能力正在越来越多地转移到模型自身内部。

我们认为 Astra 是模型智能领域的一项重大突破。

顺便提一句：当我们在 3 月发布 ARC-AGI-3 时，前沿模型的得分还 <1%，一些 Singularitarian poasters 认为这是对他们个人的侮辱，并为此大为光火。他们争辩说这个基准测试从根本上就是坏掉的、连最聪明的人类也解不出来、实际能达到的最高分只有 40% 等等。

就因为我们发布了一个未饱和的基准测试，之后我们不得不应对如潮水般涌来的侮辱和恶评帖子（hate poasts）。

事实证明，这个基准测试的校准非常完美。只要表现优于普通人，人类想要拿到 100% 是很轻松的事——你只需要比我们的人类 baseline 使用更少的动作步骤即可（这并不是一个很强的 baseline，因为我们使用的是未经筛选的人类测试者）。

因此，一旦在 agentic 通用智能方面取得实质性进展，AI 拿到 100% 自然也是完全可行的。AI 在 6 个月的时间里从 <1% 飙升至 100% 的轨迹表明，该基准测试成功记录下了近期 agentic 能力的崛起。而这种崛起的速度超出了包括我们在内的大多数人的预期。

zai 的财报纪要非常值得一读，以下是一些有趣的要点（大部分直接摘录自纪要）：

* Chat → Coding → Agent → Cowork → Autonomous AI
* 真正重要的是谁能以更快的节奏、更优的成本，持续将更强大的模型推向市场。
* 网络安全是目前验证最明确且进展最快的方向。法律服务、金融、数据分析等领域也在探索中，但仍处于早期阶段，尚未形成规模化营收；由于各自的可靠性门槛和验证机制不同，它们的商业化落地节奏也会有所差异。
* 2026 年上半年总营收达到 US$142 million，同比增长近 400%，目前主要由开放平台和 API 业务贡献。
* 截至 2026 年 8 月底，我们的 ARR 已达到 US$1.6 billion。该 ARR 是通过将月营收年化计算得出的——即 8 月营收乘以 12。海外的 Frontier-model 公司以及业内部分企业也采用了更激进的算法，即将最近一周的数据乘以 52。考虑到 GLM-5.3 的快速放量，按该方法计算的 ARR 已经突破了 US$2 billion。
* 平台营收的历史性激增主要由模型能力驱动，而非完全依赖价格弹性。
* 开放平台和 API 业务的毛利率从去年上半年的负 0.4% 上升至今年上半年的 24.6%。
* 今年上半年经调整后的净亏损约为 US$292 million，低于研发支出（US$317 million）——即毛利现已能够覆盖管理和销售费用，因此“该业务已开始自主造血支持研发”。不过目前覆盖比例不足 10%；研发费用其余约 90% 仍由资产负债表支持。
* 算力乘数（算力每投入 1 美元所产生的 API 收入）相比去年上半年增长了 14 倍。
* 截至 2026 年 8 月，平台注册用户数超过 7.4 million，较年初增长 144%。付费日活跃用户增长了 603%。
* 截至 8 月底，以 ARR 计，年化贡献超过 US$100,000、US$500,000、US$1 million、US$10 million、US$25 million 和 US$250 million 的高价值用户群体数量分别为 115、25、37、8、2 和 2 个。
* 6 天内的总使用量超过 62 trillion tokens，带动平台整体使用量提升超过 20%。（我想这大概相当于 5,000 张 B300 GPU 的算力容量）。
* Zhipu 在数据和训练环境开发上进行了长期投入，包括一支数百人的数据标注团队。GLM-5.3 相较于 GLM-5.2 取得大幅提升的一个重要原因，在于其数据环境的规模扩大了数十倍。
* 数据正在开始自我生成。模型对战（Model-versus-model）的 self-play 流程意味着，数据质量的上限不再取决于人工标注的速度，而是取决于模型自身验证结果的能力。
