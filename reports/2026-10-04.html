我好像刚刚在 9.65 秒内训练完了 NanoGPT！？

昨天，@hermanbrunborg 使用了一个在 CPU 上并行训练的连通最长精确匹配模型，在一个令人印象深刻、尚未合并的 PR 中，将 nanoGPT 的纪录从 39.9 秒缩短到了 21.5 秒。我改用了他们的成果，并将 CPU 模型推广到更大比例的 token 上，把纪录缩短到了 9.65 秒，今天早上提交了 PR。

除了我自己的贡献，我还借鉴了三个尚未合并的 PR：我的推广工作主要基于 @hermanbrunborg 的成果，也借鉴了 @nthngdy、@cyrusghane 和 Daniel Monroe 的其他工作。他们的工程实现令人非常佩服。

当然，我们所有人的纪录都还需要经过审核。正如我在 Herman 的 PR 评论中（以及我自己的 PR 描述中）提到的，在 nanoGPT 中使用 CPU 属于灰色地带。他们的 PR 首次发现了一种在运行期间有效利用 CPU 的巧妙方法，所以我很期待正式审核。

这又是一次非常有趣的挑战！尤其是昨天（可能）突破了 10 秒大关。还有很多工程技巧有待探索。

特别感谢这三个 PR 的作者带来的创新。

跟 @poteto 聊过之后，我有个大胆的观点：在 AI 时代，我们应该使用更多抽象。

你可以用抽象（配合严格的 lint 规则）缩小 agent 可选的设计空间，把它们限制在只能做出好决策的范围内。

再加上，好的抽象能让你用更少的代码做更多的事，也就更省 token。

而且，有了 agent，修复糟糕抽象造成的破坏也便宜多了。

这与很多人的想法相反：他们觉得 agent 就想直接读原始代码。它们确实能读，但这样做效率并不是最高的。

7.0 · 观点08:50 · ♥ 2,152 · ↺ 329
声称“意识产生于计算基底，而 AI 模型属于计算，所以它们很可能具有意识”，就像声称“生物由原子构成，而这块石头也由原子构成，所以它很可能是活的”一样毫无意义。

一切都是计算。有时是极其复杂的计算，比如国际象棋引擎、AlphaGo、google3 或 Linux 内核。但这并不会让它具有意识。石头由原子构成，并不意味着它就拥有同样由原子构成的生物所具有的任何特性。同样，一个静态的输入输出程序，如果*完全不具备*我们通常认为有意识的存在所具有的特性（例如信息整合、内感受、时间绑定、具身性等），那么推定它具有意识，并不比推定石头是活的更有道理。

人类尚未创造出有意识的计算机程序，也没有迹象表明我们已接近这一目标。等到我们接近时，支持机器意识的论据将建立在证据之上，并得到意识科学（这确实是一门科学）的佐证，而不是依靠毫无证据的一厢情愿和对表面形式的盲目模仿。
💡Chollet 指出的推理漏洞是：共享计算基底，不能作为拥有意识的证据；这是一项论证批评，并非新的意识实验结果。对产品判断的意义是将拟人表现与意识主张分开，后者需要可检验的机制和证据支撑。
