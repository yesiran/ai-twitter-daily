AI Picbreeder 实验：当没有人告诉 AI agents 该创造什么时，它们还能拥有创造力吗？

博客：https://t.co/qsMwcB3N5D

在我们与 MIT 和 NYU 合作完成的 #GECCO2026 新论文“In Search of the Ingredients of Open-Endedness: Replicating Picbreeder with Large Vision-Language Models”中，我们重新审视了 Picbreeder——一个已经消失的网站，在那里，人们可以在没有任何预定义目标的情况下协作演化图像。用户只是挑选他们觉得有趣的图像，于是面孔、动物、交通工具、骷髅头等意想不到的形态，便在许多代、许多不同人的接力中逐渐涌现。

我们用视觉语言模型 agents 重现了这一过程。这些 agents 会探索一个共享档案库，选择图像作为分支起点，演化出新的候选作品，发布自己的最爱，并评价其他 agents 的创作。没有目标图像，也没有对“什么算进步”的明确定义。

研究结果既展现了 AI 驱动的开放式发现的潜力，也揭示了它目前的局限。

与人类相比，VLM agents 往往会不断绕回相同类型的图像和概念。它们反复选择相似的亲代，概念跳跃的幅度更小，而且常常是在打磨一个已有的想法，而不是抛弃它去寻找真正意想不到的东西。

不过，引入个性多样化的 agent 群体能显著改善探索效果。在一些运行中，多样化的 agent 群体在语义多样性指标上接近甚至媲美人类档案库，并产生了更均衡的演化树。

我们还发现了耐人寻味的证据，表明开放式演化可以产生更稳健的表征。agents 演化出的骷髅头，在其底层神经表征受到扰动时会平滑地变化，不像直接用梯度下降优化出的骷髅头那样支离破碎——尽管其解耦的干净程度仍不及人类集体演化出的版本。

但也许最有趣的发现，是依然存在的差距。

人类似乎更擅长把幸运的意外转化为持续的创造性发现：他们能识别出意想不到的东西何时值得深入挖掘，对其加以打磨，然后实现更大跨度的概念跳跃。AI agents 也常常能注意到有趣的模式，但更容易被困在其中。

我们仍然不完全理解，是什么让人类能够以这种方式驾驭开放式搜索，也不清楚当前的 AI 系统到底缺少了哪种（或哪些）关键要素。就目前而言，研究结果表明，人类创造力中仍有某些重要的东西，是 AI agents 尚未学会复现的。

这篇论文将在 #GECCO2026 上发表，并已获得最佳论文奖提名！欢迎查看交互式博客和技术论文，了解更多细节！

Meta 给 Muse Spark 发了个“小版本”，但它可一点都不“小”。有太多信息值得细品：

- 这个模型便宜到离谱，我简直不敢相信。实际使用中，它的成本是 Fable 和 GPT 5.5 的 1/10。如果你以为开源模型会把利润卷没，那就等着看这个吧。用 MS 1.1 居然比自己托管一个开源模型还便宜…

- 编程能力的提升非常显著。这在 1.0 上确实是个短板。但 1.1 在 VibeCodeBench 上提升了 ~50%，在 SWE Bench 上提升了 ~10%。虽然还算不上 SOTA，但在这样的成本/延迟下依然极具吸引力。

- 说到延迟，哇，这个模型真快。在我们的基准测试中，它的延迟是 Opus 4.8 的 1/4，是 GPT 5.5 的 1/2。我本以为 Meta 的网络基础设施肯定很强，但真搞不懂他们施了什么魔法，能把模型托管得在高调用速率限制下推理还这么快。

- 现在有公开 API 了。这是 Meta 第一次通过托管 API 发布模型。我预计会有大量 AI 原生用户立刻热替换，把这个模型作为替代方案快速测试一番。我们很快就能看到它的表现是否足以胜任那些生产环境的用途。

- 说到 AI 原生用户，Harvey 的法律基准测试这周堪称疯狂。Grok 4.5 以 12% 的成绩在 SOTA 宝座上坐了 ~24 小时，就被 MS 1.1 以大幅跃升至 ~20% 的表现拉下了马。我怀疑很多内部评测都会出现这种令人意外的结果。很高兴能与 @harvey @gabepereyra @nikogrupen @ItsJulioPereyra 合作完成这次评测。

- 智能比以往任何时候都更加参差不齐，即使在法律、编程这样的单个领域内也是如此。保持动态灵活对每个应用和用户都有好处。为每个任务选对模型/系统，本身就是一种优势。

我们用视觉语言模型 agents 重现了这一过程。这些 agents 会探索一个共享档案库，选择图像作为分支起点，演化出新的候选作品，发布自己的最爱，并评价其他 agents 的创作。没有目标图像，也没有对“什么算进步”的明确定义。

研究结果既展现了 AI 驱动的开放式发现的潜力，也揭示了它目前的局限。

与人类相比，VLM agents 往往会不断绕回相同类型的图像和概念。它们反复选择相似的亲代，概念跳跃的幅度更小，而且常常是在打磨一个已有的想法，而不是抛弃它去寻找真正意想不到的东西。

不过，引入个性多样化的 agent 群体能显著改善探索效果。在一些运行中，多样化的 agent 群体在语义多样性指标上接近甚至媲美人类档案库，并产生了更均衡的演化树。

我们还发现了耐人寻味的证据，表明开放式演化可以产生更稳健的表征。agents 演化出的骷髅头，在其底层神经表征受到扰动时会平滑地变化，不像直接用梯度下降优化出的骷髅头那样支离破碎——尽管其解耦的干净程度仍不及人类集体演化出的版本。

但也许最有趣的发现，是依然存在的差距。

人类似乎更擅长把幸运的意外转化为持续的创造性发现：他们能识别出意想不到的东西何时值得深入挖掘，对其加以打磨，然后实现更大跨度的概念跳跃。AI agents 也常常能注意到有趣的模式，但更容易被困在其中。

我们仍然不完全理解，是什么让人类能够以这种方式驾驭开放式搜索，也不清楚当前的 AI 系统到底缺少了哪种（或哪些）关键要素。就目前而言，研究结果表明，人类创造力中仍有某些重要的东西，是 AI agents 尚未学会复现的。
