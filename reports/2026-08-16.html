关于 token 和每 token 价格。

我说过要多写一些这方面的内容，那就开始吧：一个 OpenAI token != 其他模型的 token。我们用每百万 token 多少美元来比较 AI 价格，仿佛 token 是一个标准化单位，像克或千瓦时一样。但它并不是。不同的模型会用不同数量的 token 来处理和生成完全相同的文本，这意味着更低的每 token 价格并不一定意味着更低的账单。

想象两个一模一样的披萨。一个切成 8 片，每片 $2；另一个切成 16 片，每片 $1.25。第二家宣传每片更便宜，但整个披萨要花 $20 而不是 $16。真扫兴……你的胃其实并不在乎你刚吃了多少片。

我知道你现在饿了，但说回 token。在一个涵盖英语、技术、多语言和数字文本的小型对比中，我们为 GPT-5.6 Sol 使用的分词器用了 766 个 token，而 Claude Opus 5 估计需要 1,170 个。这是非常显著的差异——大约少了 34.5% 的 token。你可以得到完全相同的文本，却要为那些额外的 token 付费。每 token 价格并不能说明这个问题。

即使修正了分词器的差异，也没有抓住更重要的点。真正重要的是每个成功结果的价格，对此你可以以基准测试为起点，但实际上你得亲自尝试，并在自己的使用场景中衡量。

模型训练公司在很大程度上白占了 METR、Redwood、Apollo 这类 NGO 以及 Goodfire 这类小型对齐公司的便宜。它们把自己相当大一部分对齐外部性转嫁给了这些机构。它们应该向自己认可的组织注入数十亿美元。

在其中一些情况下这很容易，但在另一些情况下，比如 METR——可以理解——它非常努力地保持在财务上独立于各实验室。慈善领域需要这样一个第三方（我喜欢 Coefficient Giving，但可惜它离 Anthropic 太近了）：它能可信地独立于各实验室，同时仍然接受实验室员工的捐赠，或者更进一步，直接接受实验室的捐赠，再把这些钱分发给研究对齐与控制的有前途的组织和个人。

一些慈善界人士会对此抱怨，但 OpenAI foundation 及类似机构可以为技术对齐问题或结果可验证的研究设立巨额奖金。

换句话说，如果这个行业要真正实现自我监管，整个生态系统理应从实验室的巨额财富中获得一部分注入。
💡增量：点名实验室把对齐成本外部化给 METR/Redwood/Apollo/Goodfire，方案是可信独立第三方分配实验室/员工捐赠，并用巨额奖金资助可验证对齐研究。对从业者：预期“自我监管”会变成真金白银的外部评测/控制投入；提前设计第三方审计预算、利益冲突披露和可验证研究里程碑。
