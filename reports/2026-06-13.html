我想在这里指出几个非常有趣的点：

1. 在使用相同模型时，Claude Code 实际上是性能最差的 harness，明显落后于 opencode 和 cursor cli

这就是我一直反对 LLM 公司将业务重点放在把用户锁定在他们自己的 harness 上的核心原因

他们擅长的是制造优秀的模型。但在制造好的 harness 产品方面他们很差劲，就像发电厂做不出最好的洗碗机，互联网运营商做不出最好的手机一样

如果 anthropic 想为用户着想，他们应该允许人们在他们选择的任何 harness 中使用其订阅，而不是仅锁定在 claude code 中

2. fable 5 max 仅比 gpt 5.5 xhigh 高出 1pt（77 对 76）

这符合我目前的体验 —— fable 5 确实有大模型的感觉，而且相当不错，但它并没有像他们营销宣传的那样带来巨大的飞跃，至少在构建软件方面是这样

这对 anthropic 来说实际上是令人担忧的，因为人们极不可能愿意为 1pt 的差距支付 2x 的高昂成本。我的推测是，在企业中，人们将被限制仅在一些关键任务上采用 fable 和 mythos，而不会大规模使用。

沙箱（Sandboxes）现在非常流行（Modal、E2B、AWS 等）。大多数 AI 团队在别人的机器上运行沙箱要多付 4x 以上的溢价。

隆重推出 SkyPilot Sandboxes —— 在你自己的集群上运行 BYOC 沙箱。

• 单个集群上运行 50,000+ 个沙箱
• 利用温池（warm pools）实现亚秒级启动
• 非常适合 RL rollout（让沙箱集群靠近 GPUs）

基准测试（Benchmark）显示，在更低延迟下，@skypilot_org Sandboxes 比 Modal 便宜 4-10x。完整结果见博客。
