Superlinear @superlinear_fm
用 @pidotdev 的 Pi Durable + @CloudflareDev Durable Objects 值得构建的 4 样东西：

#1 用于高风险工作流的持久化智能体

Pi Durable 可以识别被中断的操作，避免自动重放不安全的调用。想象一下，智能体给客户退款后，还没收到确认就崩溃了。你肯定不希望它给客户退款两次。
Pi Durable 会为每一步保存检查点，记录执行工具调用的意图，以及调用是否完成。崩溃后，它知道哪些操作被中断了。不安全的调用不会被盲目重试，因此你的应用可以先检查付款是否成功，再继续执行。

#2 团队共享智能体

Pi Durable + Cloudflare Durable Objects 是多人协作式智能体编程的绝佳基础。
一个 Durable Object 保存智能体的持久化状态。多个客户端可以连接到同一个会话，传入的消息可以排队，也可以用来引导智能体，更新则以流式方式推送给所有人。
想象一下，智能体接手一个 GitHub issue 并着手处理 PR，团队成员则通过手机、浏览器或终端查看或引导同一段对话。@pidotdev 的 shared-chat 教程演示了这一点。

#3 随处运行的智能体

@badlogicgames 构建了一个 Pi Durable Android 应用，在他的手机上运行智能体运行框架，并将状态存储在本地，而模型调用则在远端进行。
Pi Durable 将智能体状态与执行分离，支持可插拔的存储和执行后端。只要有兼容的 JavaScript 运行时，就能运行这套框架，而其中的工具可以在另一台机器上执行。你的持久化智能体无需仅仅为了保存状态，就一直开着终端或云服务器；运行框架可以在本地、手机或云端运行。

#4 基于智能体状态构建新工具

这是最让我们兴奋的一点。
Pi Durable 会持久化保存结构化任务、检查点和被中断的操作。这意味着你可以直接检查智能体的执行状态，无需让模型重新还原发生过什么。
我们尝试将 Pi Durable 放进一个 Cloudflare Durable Object 中，在不唤醒智能体的情况下，可视化展示它存储的状态。
想象一下，利用这些数据构建：
- 调试面板，准确显示智能体在哪一步崩溃。
- 可靠性指标，显示哪些工具调用反复失败或需要恢复。
- 多人协作面板，显示待处理任务、谁引导过智能体，以及具体时间。
有意思的是，持久化执行状态成了可用于构建工具的新原语，而不只是用于崩溃恢复的东西。
