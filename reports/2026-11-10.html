Artificial Analysis @ArtificialAnlys
Meta 最新模型 Muse Ember 在 Artificial Analysis Intelligence Index 上得分 36，与 Claude Haiku 5.5 (max) 持平，每项任务的成本却只有其三分之一

Muse Ember 是 Meta 最新的高效档模型系列，输入和输出 token 的定价与 Claude Haiku 5.5 和 GPT-6 Luna 相同

主要结论：

➤ 在 max 和 xhigh 推理强度下，均位于 Intelligence Index 得分与每项任务成本的帕累托前沿。Muse Ember (max) 是得分达到 36 或以上的模型中最便宜的，每项任务 $0.14；Muse Ember (xhigh) 得分 34，每项任务 $0.12。Claude Haiku 5.5 (max) 与 Muse Ember (max) 得分相同，但成本为 $0.41，接近其 3x。Muse Ember (max) 也比 DeepSeek V4.1 Flash 1017 (max, 33, $0.60) 和 GLM-5.3-Flash (28, $0.58) 便宜约 4x

➤ 比 Muse Wonder 低 8 分，每项任务成本约为其 1/50。Muse Wonder (max) 得分 44，每项 Intelligence Index 任务成本为 $6.95

➤ 在 AutomationBench-AA 上表现突出。Muse Ember (max) 在 AutomationBench-AA 上得分 68.1%，与 Muse Wonder (max) 持平；在 GDP.pdf 上超过 Claude Haiku 5.5 (max)（22.8% 对 20.8%），但在 AA-Briefcase 上落后于它（1521 对 1574 Elo）

➤ 在我们的 Intelligence Index 评测中，智能体编程表现有好有坏。它在 Terminal-Bench 4.0 上超过 Claude Haiku 5.5 (max)（40.9% 对 32.8%），但在 FrontierCode 2.0 上落后（27.2% 对 34.9%）

➤ 在各自的编程智能体中运行时，领先于定价相近的模型。在 Muse Code 中，Muse Ember (max) 在 Artificial Analysis Coding Agent Index 上得分 46，领先于在 Claude Code 中运行的 Claude Haiku 5.5 (max, 37)，以及在 Codex 中运行的 GPT-6 Luna (max, 31)

➤ 知识是主要短板，但它很少产生幻觉。它在 AA-Omniscience 上的准确率为 21.1%，是我们比较的智能水平相近模型中最低的；Claude Haiku 5.5 (max) 为 34.7%，Gemini 3.8 Flash (high) 为 50.5%。这主要是因为它拒绝回答 64% 的问题，使其幻觉率保持在 17.4%，是 Claude Haiku 5.5 (max) 的一半

其他详情：
➤ 定价：每 1M tokens，输入 $0.10 / 缓存输入 $0.004 / 输出 $0.50
➤ 推理强度：展示的结果采用 max 强度，智能水平与成本图中也包含 xhigh ➤ 可用渠道：Meta 的第一方 API 和 Muse Code
💡这条补充了更具体的竞争定位：宣称与 Haiku 能力相当、单任务成本降至三分之一，并超过 Luna。对已有 Haiku 工作负载有替换评估价值，但缺少具体版本和任务集，结论不能外推到全部场景。

Larry Dial @classiclarryd
分享一下 Marin 535B-A23B 架构背后的思考过程。它上周完成了基于 18T tokens 的预训练：https://t.co/ZdeshNHhcy

今年早些时候，Marin 项目在 Open Athena 有 6 名全职员工，既有 AI 领域的资深人士，也有像我这样入行不久的人。作为一名 IC，我从团队中学到了很多。此后，我们用一个月让 B200 GPU 集群运行起来，将 GPU 规模扩大了 300x，训练了一个拥有 535 billion 参数的模型，公开预测了这次训练的表现，全程直播了训练过程，最终以略好于预测的结果完成预训练，期间没有出现任何不稳定情况。

当然，训练模型的结果并非简单的成败二选一。我为我们取得的进展感到自豪，也对未来还有多少值得探索的空间充满期待！团队最近壮大了，很快就会对模型开展 SFT 和 RL，并在过程中持续分享发现。
